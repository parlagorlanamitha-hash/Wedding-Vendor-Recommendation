# 💍 Wedding Vendor Recommendation System

## 📌 Project Overview

The **Wedding Vendor Recommendation System** is a Machine Learning-based project designed to help users find suitable wedding vendors according to their requirements and preferences. The system analyzes factors such as **budget, location, vendor category, ratings, and user preferences** to provide relevant recommendations.

## 🎯 Objectives

* Recommend suitable wedding vendors based on user requirements.
* Help users find vendors within their budget.
* Consider vendor ratings and location while making recommendations.
* Reduce the time and effort required to search for wedding services.
* Provide personalized vendor recommendations using Machine Learning.

## 🛠️ Technologies Used

* **Python**
* **Machine Learning**
* **Pandas**
* **NumPy**
* **Scikit-learn**
* **Jupyter Notebook / VS Code**

## ⚙️ Features

* Vendor recommendation based on user preferences.
* Budget-based vendor selection.
* Location-based recommendations.
* Vendor category selection.
* Rating-based recommendations.
* Personalized results.


## 🔄 Working Process

1. Collect wedding vendor dataset.
2. Clean and preprocess the data.
3. Select relevant features such as budget, location, category, and ratings.
4. Train the Machine Learning model.
5. Accept user requirements as input.
6. Generate suitable vendor recommendations.
7. Display the recommended vendors to the user.

## 📊 Input

The system can consider:

* Vendor Category
* Location
* Budget
* Rating
* User Preferences

## 📈 Output

The system provides a list of **recommended wedding vendors** that best match the user's requirements.
